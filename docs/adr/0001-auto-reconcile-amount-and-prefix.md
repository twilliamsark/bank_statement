# Auto Reconcile uses amount + 21-char prefix over all committed same-card transactions

Auto Reconcile fills `UnreconciledTransaction` category/subcategory only when a same-`CreditCardAccount` committed `CreditCardTransaction` (year-end or previously saved monthly) shares both `amount_cents` and `description[0, 21]`, and all such matches agree on one `(category, subcategory)` pair. We kept amount in the key so unrelated merchants with a shared short prefix cannot steal categories, kept the 21-char prefix aligned with `import_fingerprint`’s description slice (fingerprint still also includes date and is used only for potential-duplicate flagging), and included monthly-committed rows so mid-year category learning works after year-end data goes stale. Rejected alternatives: 8-char prefix without amount (too loose), and year-end-only match sources (too brittle once monthly history exists).
